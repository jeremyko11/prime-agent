# 损失核定指南（核损）

核损目标：把索赔金额核减到"保险事故直接造成的、必要合理的、按保单约定应赔的"金额。**逐项核定，每项留痕。**

## 一、核定顺序（每项损失都过一遍）

1. **因果性**：该项损失是否由本次承保事故直接造成？
   - 剔除：事故前已存在的缺陷/旧损、自然老化、正常施工损耗、设计错误导致的返工、缺陷本身。
   - 受损对象同时有旧伤和新伤的，按新旧程度分摊，不能全算本次事故。
2. **经济性（修复 vs 更换）**：
   - 能修复且修复费用 < 更换费用的，按修复赔；修复后功能/寿命无法恢复的，可更换。
   - 更换时扣残值（受损旧件残值）；修复时核对是否包含"以新换旧"的增值部分。
   - 只恢复到**出险时状态**，不是恢复到全新状态（除非保单约定重置价值）。
3. **计价基础**：
   - 重置价值/实际价值：看保单"保险价值"约定。通常工程险按重置价值（重建成本）投保；机器/设备类按重置价值或账面净值，注意折旧。
   - 单价参照：合同价/中标价 > 定额（当地现行定额）> 市场询价。三者取合理者，并说明依据。
4. **工程量审核**：
   - 数量 × 单价 = 金额。逐项核对数量（图纸/清单/计量资料/现场照片/查勘记录），防止虚报、重复、搭车。
   - 重复计算高发点：同一材料同时计入"材料损失"和"工程修复"；土方/支护同时计入两处；人工费重复计取（定额已含的又单列）；税金、管理费、利润重复。
   - 索赔清单与合同结算单交叉核对，已结算/已支付部分不得重复索赔。
5. **残值**：
   - 受损物资残余价值（可回收变卖、可再利用部分）应从赔款中扣减。
   - 残值 = 受损物资现状价值（可询回收商/市场），单据留档。
   - 注意：扣残值还是"残值归被保险人、全额赔付"以保单约定为准。
6. **施救费用**：
   - 必要、合理的为防止或减少损失而支付的费用，单独列项。
   - 与损失赔款合计一般不超过保险金额（按条款）；只赔与承保风险相关的施救。
   - 常见争议：抢险人工费、设备租赁费、排水抽水费——核对工时、台班、单价是否合理。
7. **场地清理费用**：
   - 清理受损财产残骸的费用，通常有**单独限额**（如保额的 10%-20%）且可能要求共保。
   - 只含清理、搬运、处置残骸，不含修复费用。
8. **特别约定/分项限额**：图纸资料费、临时建筑、施工机具、盗窃、地震洪水等可能各有分项限额或单独免赔，逐项检查。

## 二、常用审核手段

- **三单核对**：索赔清单 ↔ 合同/中标价 ↔ 发票/结算书。金额不一致的列差异表。
- **照片/查勘记录比对**：受损部位、范围、程度与申报是否一致。
- **数量反推**：用图纸尺寸/材料规格反算工程量，超算部分核减。
- **市场询价**：对明显偏离市场价的单价，给出合理区间并建议询价（报告注明"建议询价"事项）。
- **折旧处理**：机器、设备、周转材料（模板、脚手架、围挡）按使用年限和已用年限计算成新率。
- **避免重复**：同一事故中，同一项目不得同时出现在"物质损失"和"施救费"或"清理费"中。

## 三、核减原因分类（报告用词）

| 分类 | 说明 |
|---|---|
| 不属于承保责任 | 除外责任/超出保险期间/非承保标的 |
| 与事故无因果关系 | 事故前已存在、自然损耗、非本事故造成 |
| 超过必要合理范围 | 过度修复、搭车修复、以新换旧增值 |
| 数量核减 | 工程量虚报、重复计算 |
| 单价核减 | 单价高于合同/定额/市场 |
| 残值扣减 | 受损物资残余价值 |
| 免赔/比例/限额 | 保单约定的免赔额率、不足额比例、分项限额 |
| 资料不足待定 | 缺依据，暂按保守核定并请补充 |

## 四、工作底稿要求

- 每项：申报金额 → 核定金额 → 核减金额 → 核减原因 → 依据（文件+页码/行）。
- 全部计算保留算式，报告可追溯。
- 对资料不足的项目，宁可"暂列待定"并列出所需补充资料，不猜测填数。
