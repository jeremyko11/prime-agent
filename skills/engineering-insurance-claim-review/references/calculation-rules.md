# 赔款计算规则与案例

> 公式为通用框架，具体以保单条款、特别约定、批单为准。计算必须展示算式。

## 一、关键概念

- **保险金额（Sum Insured, SI）**：保单载明的各项/总保险金额。
- **保险价值（Insurable Value, IV）**：出险时保险标的的实际价值（重置价值或约定价值，看条款）。
- **损失金额（Loss, L）**：核损后属于承保责任范围内的损失（已扣残值前的物质损失）。
- **残值（Salvage, S）**：受损物资残余价值。
- **免赔额/免赔率（Deductible）**：每次事故免赔额（绝对金额）和/或免赔率，条款常约定"以两者中高者为准"或分别适用不同事故类型（地震、洪水、其他）。
- **施救费用（Sue & Labour, SL）**：合理施救费用，通常另行赔付，与损失合计不超过保险金额（按条款）。

## 二、公式

### 1. 足额投保（SI ≥ IV，或保单无共保/比例约定）

```
应赔物质损失 = (核损金额 - 残值) × (1 - 免赔率)  − 免赔额    （若条款为"取高"则比较后取高者）
```

条款常见写法：
- "每次事故免赔额 X 元或损失金额的 Y%，以高者为准" → 免赔 = max(X, 损失×Y%)
- 单纯免赔额 → 免赔 = X（损失 ≤ X 时不赔）
- 单纯免赔率 → 免赔 = 损失 × Y%

注意免赔率的分母约定：按"损失金额"还是按"保险金额"计算，按条款原文。

### 2. 不足额投保（SI < IV，比例赔付）

```
赔付比例 = SI / IV
应赔物质损失 = (核损金额 - 残值) × (SI / IV) × (1 - 免赔率) − 免赔额
```

- 比例赔付是否适用以保单为准（有的工程险条款约定"以重置价值投保则视为足额"，有的对部分标的约定"第一危险"赔偿）。
- 免赔在比例赔付后扣除还是比例赔付前扣除，按条款；常见为比例赔付后再扣免赔。
- 保险金额是否含施救费/清理费限额，按分项约定。

### 3. 施救费用

```
施救费赔款 = 核定的合理施救费 × (SI / IV)（不足额时按条款比例）− 免赔（按条款）
且：损失赔款 + 施救费赔款 ≤ 保险金额（通常约定）
```

### 4. 重复保险分摊

同一标的在多家保险公司投保且保险金额合计超过保险价值的：

```
本公司赔付 = 应赔金额 × (本公司保险金额 / 各保单保险金额合计)
```

（以条款"重复保险分摊条款"为准，常见为比例分摊制。）

### 5. 场地清理费

```
清理费赔款 = 核定清理费（≤ 保单约定的清理费限额）
```

### 6. 含第三者责任的情况

工程险常把物质损失与第三者责任分项；本技能侧重物质损失定损，第三者责任按保单责任限额与免赔另行处理，需单独列明。

## 三、计算步骤（报告展示用）

1. 列损失明细：逐项 核定金额、残值。
2. 物质损失合计 = Σ(核定金额 - 残值)。
3. 判断足额/不足额 → 算比例赔付。
4. 按事故类型套用免赔额/率 → 扣免赔。
5. 加施救费、清理费（各按规则）。
6. 重复保险分摊（如有）。
7. 汇总：本次事故应赔金额。

## 四、示例

**案例**：CAR 保单，保险金额 1,000 万（永久工程），保险价值 1,200 万（出险时），暴雨事故。
索赔 80 万；逐项核损后核定 65 万，其中受损钢材残值 3 万。
条款：免赔额 2 万或损失金额的 5%，以高者为准；不足额按比例赔付；施救费 6 万（核定合理）。

```
物质损失 = 65 - 3 = 62 万
比例赔付 = 62 × (1000/1200) = 51.67 万
免赔 = max(2, 51.67 × 5% = 2.58) = 2.58 万
应赔物质损失 = 51.67 - 2.58 = 49.09 万
施救费 = 6 × (1000/1200) = 5 万（扣免赔与否按条款；本例条款施救费不扣免赔）
合计 = 49.09 + 5 = 54.09 万
（校验：≤ 保险金额 1000 万 ✓）
```

## 五、易错点

- 免赔额/率按"每次事故"适用，多损失归入同一事故只扣一次。
- 先扣残值再算比例赔付。
- 施救费单独列，不并入物质损失后再扣免赔（除非条款约定）。
- 保险金额是否随工程进度自动恢复/自动增加（"自动升值条款"），涉及 IV 判断。
- 已付赔款、预赔款、上次事故未决赔款不要混入本次计算。
- 金额单位统一（万元/元），报告通篇一致。
