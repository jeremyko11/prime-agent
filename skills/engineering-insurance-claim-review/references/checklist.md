# 材料清单与审核清单

## 一、必需材料（尽量齐全再开工）

| 类别 | 材料 | 用途 | 优先级 |
|---|---|---|---|
| 承保 | 保单正本/批单/特别约定清单 | 核责、算赔款 | 必需 |
| 承保 | 投保单、报价单（如有） | 核对保额、保险价值 | 建议 |
| 出险 | 出险通知书/报案记录 | 事故时间、原因 | 必需 |
| 出险 | 事故报告/情况说明 | 事故经过 | 必需 |
| 查勘 | 查勘记录、现场照片、视频 | 损失范围核实 | 必需（照片至少要有） |
| 损失 | 索赔清单（明细：项目/数量/单价/金额） | 核损主表 | 必需 |
| 损失 | 合同、中标价、结算书、工程量清单 | 单价/工程量核对 | 建议 |
| 损失 | 发票、付款凭证、收据 | 金额真实性 | 建议 |
| 损失 | 修复方案/报价单（已修复的含结算） | 修复费用核定 | 视情况 |
| 其他 | 气象证明、报警记录（台风暴雨/盗窃） | 出险原因佐证 | 视情况 |
| 其他 | 施救费用单据 | 施救费核定 | 视情况 |
| 其他 | 鉴定/检测报告（结构、材料） | 原因与损失程度 | 视情况 |

## 二、信息提取核对表（提取后逐项打勾）

- [ ] 保单号、险种、被保险人、工程名称
- [ ] 保险期间（起止日期，注意批改）
- [ ] 保险金额：总保额、分项保额（物质损失/第三者责任/清理费/施工机具）
- [ ] 保险价值约定方式（重置价值/账面价值/约定价值）
- [ ] 每次事故免赔额、免赔率（含分事故类型：地震/洪水/其他）
- [ ] 扩展条款及批单清单（是否含设计错误、原材料缺陷、盗窃、保证期、施救等）
- [ ] 保证期（如有）：起止、承保范围
- [ ] 出险时间、地点、事故类型、报案时间
- [ ] 索赔总金额与明细行数
- [ ] 上次事故/未决赔款情况（防止重复）

## 三、核责检查清单

- [ ] 出险时间在保险期间内（含扩展/保证期）
- [ ] 受损标的属于承保标的
- [ ] 致损原因属于承保风险
- [ ] 未命中除外责任；命中的检查是否有扩展条款
- [ ] 近因判断有依据
- [ ] 批单效力已考虑（批单优先于主条款）

## 四、核损检查清单

- [ ] 每项损失与事故有因果关系
- [ ] 修复vs更换已比较，更换已扣残值
- [ ] 单价有依据（合同/定额/市场）
- [ ] 数量已核对（图纸/清单/照片），无虚报重复
- [ ] 无重复计算（材料损失与修复重复、人工费重复、已结算重复）
- [ ] 残值已核定并扣减
- [ ] 施救费必要合理、未超限额
- [ ] 清理费未超分项限额
- [ ] 折旧/成新率已按实际年限计算
- [ ] 特别约定与分项限额逐项适用

## 五、赔款计算检查清单

- [ ] 足额/不足额判断正确（SI vs IV）
- [ ] 比例赔付计算正确（SI/IV）
- [ ] 免赔额/率选择正确（按事故类型，取高者）
- [ ] 先扣残值、再比例、再免赔的顺序正确
- [ ] 施救费单独计算且未超保险金额
- [ ] 重复保险分摊已考虑
- [ ] 各金额单位一致，三遍核对一致

## 六、材料缺口处理

缺必需材料时：列出缺口清单（表格），明确"需要用户补充什么、用于什么判断"，暂停对应环节；用户可以只提供文本摘录时，标注"未经原文核对"。绝不编造保单数据。
