# 工程险理赔审理与定损

收到工程险案件材料并要求审理/定损/核赔时使用。按以下流程执行，详细规则见 `references/` 对应文件。

## 工作流程总览

1. 解析材料
2. 材料完整性检查（缺材料先向用户要，不凭空假设）
3. 信息提取与交叉校验
4. 承保责任审核（核责）
5. 损失核定（核损）
6. 赔款计算
7. 出具定损报告
8. 质控复核

## 1. 材料解析

- **PDF/Word**：优先用系统 `pdftotext`；无则在本项目环境安装解析库（`uv pip install pdfplumber pymupdf`）。扫描件若为图片页，逐页转图片后用 `attach_image` 查看（模型支持视觉时），或请用户提供可复制文本。
- **Excel/CSV 索赔清单**：用 pandas 读取，保留逐行明细用于核损，不丢失行级数据。
- **图片（照片/扫描件/图纸）**：用 `attach_image` 直接查看。
- 所有提取的保单数据（保险期间、保额、免赔、扩展条款）必须能回溯到原文，报告里注明出处页/文件。

## 2. 材料完整性检查

必需材料清单见 `references/checklist.md`。缺失关键材料（保单、索赔清单）时列出缺口清单请用户补充后再继续，不要用假设数字继续计算。

## 3. 信息提取与交叉校验

提取保单信息、事故信息、索赔信息（模板见 `references/report-template.md` 第一节）。交叉校验：出险时间 vs 保险期间；出险地点/工程部位 vs 保险标的；索赔金额 vs 合同/发票/结算书；同一损失是否在多个单据中重复申报。

## 4. 核责（承保责任审核）

按顺序判断，任一环节不成立则该项责任不成立：

1. **保险期间**：出险时间是否在保险期间（含保证期/扩展期间）内。
2. **保险标的与承保风险**：损失项目是否属于保单标的（永久工程、临时工程、材料、施工机具、场地清理费等），致损原因是否属于承保风险（自然灾害/意外事故，按保单措辞）。
3. **除外责任**：是否落入除外责任（设计错误、原材料缺陷、工艺不善、自然磨损、锈蚀、停工/利润损失、罚金违约金、未清除现场等，见 `references/coverage-and-exclusions.md`）。
4. **扩展条款**：被除外的事项是否有对应扩展条款恢复承保（如设计错误扩展条款、原材料及工艺缺陷条款）。
5. **近因原则**：损失近因是否为承保风险；连续原因中断是否改变定性。
6. **责任结论**：全部属责 / 部分属责（逐项列明）/ 不属责，每项给依据。条款判断以**保单原文**为准，references 仅为通用参照。

## 5. 核损（损失核定）

对索赔清单**逐项**核定，方法见 `references/loss-assessment-guide.md`：

- 损失与保险事故的因果关系（只核事故直接造成的损失，剔除自然损耗、老化、缺陷本身）。
- 修复 vs 更换的经济性比较；实际价值 vs 重置价值（折旧与成新率）。
- 单价与工程量合理性：对照合同价/中标价、定额、市场询价；检查虚报数量、重复计算、搭车修复、关联项重复索赔。
- 残值扣减（受损物资残余价值，含变卖或利用价值）。
- 施救费用（必要合理、单独列项、通常不超保险金额）与场地清理费用（注意单独限额与共保）。
- 每项核减必须写明核减原因和依据。

## 6. 赔款计算

- 公式与案例见 `references/calculation-rules.md`：足额/不足额投保比例赔付、免赔额/免赔率（按条款取大）、残值、施救费、重复保险分摊、保证期/特别约定限额。
- 报告必须展示计算过程：每个数字的来源、算式、中间结果。

## 7. 输出定损报告

按 `references/report-template.md` 出具 Markdown 定损报告。若用户需要 Word，将 Markdown 转为 docx（pandoc 或 `uv pip install pypandoc` / python-docx）。

## 8. 质控复核

- 金额三遍核对：提取值 → 计算 → 报告成文，三次一致。
- 明确区分"事实"与"判断"；所有假设列"假设与待确认事项"一节，数据矛盾处向用户求证。
- 检查是否有遗漏的免赔、限额、特别约定、批单。

## 注意事项

- 你是审核辅助工具：责任认定与最终核损金额建议由持证核赔/公估人员确认后生效。
- 不虚构保单条款内容；条款以保单原文为准，references 是通用参照。
- 报告用中文，措辞客观、可追溯。
